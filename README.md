# VantageEngine

Motor de sitios comerciales **white-label** con identidad, tema, contenido y módulos configurables en tiempo real.

- **Backend:** Spring Boot · Java 21 · monolito modular (Spring Modulith) · MySQL 8.4 · Flyway · Spring Security + JWT en cookie HttpOnly
- **Frontend:** Angular (standalone, zoneless, Signals, lazy loading) · design tokens en CSS custom properties
- **Despliegue:** Docker + Docker Compose

> Estado: **fase de planificación**. El código se construye siguiendo la hoja de ruta del plan técnico.
